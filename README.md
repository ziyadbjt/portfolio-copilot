# Portfolio Copilot

Outil Python de sélection d'actions, de construction de portefeuille cœur/satellite et de risk management.
Lecture seule : l'outil propose, l'humain décide, aucun ordre n'est jamais passé.

> En construction (phase 1).

## Installation

```bash
conda env create -f environment.yml
conda activate portfolio-copilot
pytest
```
